# בדיקות גרסה 2.9

- בניית C# באמצעות build.ps1.
- tools/test-offline.ps1: שמירה וטעינה של הרצאות, תאריכים, תיקיות, חתימת מקורות, שינוי הרצאה קודמת, הקלטות ידניות, שמות והתנגשויות.
- tools/test-ui.cjs: בדיקות ממשק ב-Edge עם נתוני דמה בלבד. התקנת הכלי: `npm install --prefix build/test-tools playwright-core@1.56.1`; הרצה: `node tools/test-ui.cjs`.
- tools/test-downloads.ps1: עברו הורדה רגילה, blob וחלון קופץ ב-WebView2 מול שרת HTTP מקומי, כולל מנגנון אישור הורדות מרובות. האישור בבדיקה ניתן רק לכתובת שרת הבדיקה; ללא חשבון HIT וללא Claude.

## בדיקות ידניות לפני הפצת Release

1. התחברות ל-Moodle, לפורטל ול-CS24 והורדת קובץ מכל אחד, לרבות תצוגת PDF או חלון קופץ.
2. יצירת שתי הרצאות עם חומר אמיתי, יצירת סיכום הרצאה 2 ובדיקת השימוש הנכון בחומר הרצאה 1 ובפתרונות התרגילים. בדיקת PDF ודף HTML.
3. הורדת הקלטת Zoom עם הרשאה ובדיקת התמלול כאשר זמין.
4. עדכון התקנה ישנה ובדיקת שמירת ההגדרות והחומר; גרסאות ישנות עדיין מריצות את מנגנון העדכון הישן עד שהן משודרגות.

הבדיקות האוטומטיות אינן מאמתות התחברות לאתרים, הרשאות הורדה של מרצה או איכות סיכום שנוצר ב-AI. לא מתבצעת בהן קריאת AI בתשלום.
