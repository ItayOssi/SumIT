# SumIT 1.0.21 (macOS)

- **הסילבוס בלבד בהורדת הסילבוס.** "סנכרן את הסילבוס" ו"הורד סילבוס מה-Moodle מחדש" מכניסים לתיקיית מידע הקורס רק את הסילבוס ומידע כללי על הקורס. קודם נכנסו לשם גם הרצאות, תרגילים ומבחנים שהזכירו את המילה "סילבוס" איפשהו, כל מה שהיה ביחידה "מידע על הקורס", וכל התוכן של קובץ zip עם השם "סילבוס". הקבצים האלה נכנסו לקריאת הקורס ויכלו לשבש את המרצה, הרכב הציון והתאריכים שהאפליקציה מזהה.
  - קובץ נחשב סילבוס לפי השם שלו, או לפי העמודים הראשונים: כותרת כמו "סילבוס" עם חלק של סילבוס (מטרות הקורס, הרכב הציון, דרישות קדם, ביבליוגרפיה), או שלושה חלקים כאלה.
  - קבצים ששמם הרצאה, מצגת, תרגיל או מבחן לא נכנסים, גם כשהם בתוך zip.
  - הסילבוס נבדק ראשון, כך שבקורס גדול הוא לא מתפספס.
  - הקבצים שירדו לבדיקה נמחקים בסוף, כולל מה שהצטבר ב-`.sumit/discovery` מגרסאות קודמות.
- הורדת המבחנים והפתרונות לא השתנתה.

נבדק: 88 בדיקות נסיגה (82 קיימות ו-6 חדשות על זיהוי הסילבוס וחילוץ zip), והרצה של כל תהליך הורדת הסילבוס מול Moodle מדומה: נכנסו רק הסילבוס וקובץ שהתוכן שלו סילבוס; הודעה, הרצאה וסיכום שהזכירו את הסילבוס לא נכנסו.
