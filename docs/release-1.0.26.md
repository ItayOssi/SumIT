# SumIT 1.0.26 (macOS)

- **macOS כבר לא אומר שהאפליקציה "פגומה".** עד עכשיו SumIT לא הייתה חתומה, ולכן כשהורדתם אותה בדפדפן macOS הודיע שהיא פגומה ואי אפשר לפתוח אותה, למרות שהקובץ תקין. מעכשיו היא חתומה (חתימה בסיסית, בלי רישום אצל Apple). בפתיחה הראשונה macOS יגיד שאי אפשר לאמת את המפתח, ואפשר לאשר דרך **הגדרות המערכת ← פרטיות ואבטחה ← "פתח בכל זאת"**, בלי Terminal.
- מי שמותקנת אצלו 1.0.25 מקבל את הגרסה הזו לבד: כשמופיע "הורד והתקן בסגירה", לוחצים, וסוגרים את האפליקציה או מפעילים אותה מחדש.

נבדק: 99 בדיקות נסיגה. בבנייה ב-GitHub נבדק ש-SumIT.app חתומה ושהחתימה תקינה, גם באפליקציה שבתוך ה-ZIP שהעדכון האוטומטי מתקין. שחרור בלי חתימה תקינה נעצר.
