# SumIT 1.0.25 (macOS)

- **עדכונים אוטומטיים לגרסת ה-Mac.** עד עכשיו בדיקת העדכונים ב-Mac הסתכלה על הגרסאות של Windows. עכשיו היא מחפשת את הגרסה האחרונה ל-Mac, לפי סוג המעבד (Apple Silicon או Intel). כשיש גרסה חדשה מופיע באנר "הורד והתקן בסגירה": האפליקציה מורידה את הגרסה, בודקת שהקובץ זהה לזה שפורסם ושזו באמת הגרסה הנכונה, ומחליפה את SumIT.app כשסוגרים אותה. "הפעל מחדש עכשיו" מתקין ופותח מיד. ההגדרות והקורסים נשארים. אם האפליקציה רצה מתוך ה-DMG או מתיקייה שאין הרשאה לכתוב בה, נפתח דף ההורדה כמו קודם.
- **אודות בהגדרות.** בסוף מסך ההגדרות יש כרטיס "אודות" שמציג את מספר הגרסה ואת המערכת (macOS או Windows), עם כפתור "בדוק עדכונים".

חשוב: מי שמותקנת אצלו גרסה 1.0.24 או קודמת צריך להתקין את 1.0.25 ידנית פעם אחת, כי הגרסאות הקודמות עדיין מחפשות עדכונים בגרסאות של Windows. מ-1.0.25 והלאה העדכונים מגיעים לבד.

נבדק: 99 בדיקות נסיגה (95 קיימות ו-4 חדשות: בחירת הגרסה האחרונה ל-Mac ולא של Windows או טיוטה, הקובץ הנכון למעבד, אין החלפה מחוץ לאפליקציה ארוזה, והחלפת SumIT.app אחרי היציאה). הבחירה נבדקה גם מול רשימת הגרסאות האמיתית ב-GitHub, וה-ZIP של 1.0.23 נבדק: ה-sha256 תואם לזה שמפרסם GitHub, ו-SumIT.app נמצא בשורש עם מספר הגרסה הנכון.
