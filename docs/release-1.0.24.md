# SumIT 1.0.24 (macOS)

- **הצ'אט על הסיכום ממשיך לענות גם כש-Gemini לא זמין.** אם Gemini לא עונה, השאלה עוברת ל-ChatGPT, ואם גם הוא לא זמין, ל-Claude (עם מפתח API של Claude). כל ההתכתבות עוברת יחד עם השאלה, כך שהצ'אט החלופי ממשיך מאותה נקודה. מעל השיחה מופיע איזה מנוע ענה, למשל "ChatGPT לא זמין — ממשיך עם Claude".
- **תשובות קצרות וממוקדות.** הצ'אט עונה ישר לעניין, בלי הקדמה ובלי סיכום בסוף, בעד כ-120 מילים. עם מפתח API התשובה מוגבלת גם בפועל, כך שנחסכת מכסה. כרטיסי הזיכרון לא מושפעים מההגבלה.
- **שאלה מודבקת מנוקה.** כשמדביקים שאלה מאתר או מסמך, עיצוב ורווחים כפולים מוסרים לפני השליחה, והנוסחאות נשארות כמו שהן.
- **מודלים עדכניים למפתח Gemini.** עם מפתח API, ברירת המחדל היא Gemini Flash העדכני (`gemini-flash-latest`), ואם מודל שנבחר כבר לא קיים, האפליקציה עוברת מיד למודל הבא. בהגדרות אפשר לבחור Flash, Flash-Lite או Pro. כשמחוברים עם חשבון Google, שום דבר לא השתנה.

נבדק: 95 בדיקות נסיגה (89 קיימות ו-6 חדשות: מעבר מ-Gemini ל-ChatGPT ול-Claude עם כל ההתכתבות, הגבלת אורך התשובה בצ'אט בלבד, מעבר ממודל שלא קיים, וניקוי שאלה מודבקת). נבדקו גם בקוד: הסרגל המתקפל, ייבוא ZIP של סיכום חבר (נחסמים נתיבים מחוץ לתיקייה, קישורים וקבצים גדולים מדי), בחירת תיקיית OneDrive, ושמירת המפתחות ב-Keychain בלי DPAPI.
