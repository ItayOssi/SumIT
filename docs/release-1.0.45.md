# SumIT 1.0.45 (macOS)

- **ההתחברות ל-Google Drive עובדת.** ב-1.0.44, אחרי שאישרת בדפדפן, האפליקציה הציגה "invalid client" והסנכרון לא התחבר. הסיבה הייתה שהסוד של האפליקציה נשמר בבנייה כקובץ ההגדרות המלא של Google, ולא כמחרוזת הסוד בלבד. עכשיו האפליקציה לוקחת ממנו רק את הסוד, ובנייה בלי סוד תקין נכשלת כבר בשלב הבנייה ולא מגיעה למשתמשים.

נבדק: 502 בדיקות נסיגה, כולל בדיקה חדשה לסוד בכל הצורות שבהן Google מוסרת אותו.
