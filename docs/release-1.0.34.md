# SumIT 1.0.34 (macOS)

- **תיקון: פיצ'רים שלא הופיעו בגרסה הרגילה.** מסלול הלמידה (בטא), "אני תקוע, מאיפה מתחילים?", "מה לעשות בבלוק הזה?", היומנים והחזרות על כרטיסי הזיכרון הופיעו במצב demo אבל לא באפליקציה הרגילה.
  - **הסיבה.** האפליקציה מגלה אילו פיצ'רים זמינים בשאלה ל-host מיד כשההגדרות מגיעות. בגרסה הרגילה ההגדרות הגיעו לפני שכל הסקריפטים בדף נטענו, ולכן השאלה לא נשלחה והפיצ'רים נשארו מוסתרים. במצב demo התשובה מאחרת במכוון, ולכן שם זה עבד.
  - **התיקון.** השאלה נשלחת גם אחרי שהדף נטען במלואו, פעם אחת לכל פיצ'ר.

אחרי העדכון, "מסלול למידה" מופיע בסרגל הצד. אם עדיין לא, סגור את האפליקציה ופתח אותה מחדש.

נבדק: 310 בדיקות נסיגה, והרצה של האפליקציה במצב רגיל (לא demo) עם בדיקה שכל הפיצ'רים מופיעים. לא נבדק בצילום מסך.
