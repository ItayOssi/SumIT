# SumIT 1.0.23 — תמונות בצ׳אט, קישורי הרצאות קודמות, דוח למפתח ושיפורי מידע קורס

## מה חדש

**תמונות בצ׳אט הסיכום (עד 6)** — אפשר להדביק תמונות ישירות לשיחה, לצרף קבצי תמונה, וכל סימון מהסיכום מצטרף כתמונה נפרדת לרשימה. לכל תמונה כפתור הסרה עצמאי. כל התמונות מועברות גם למנוע החלופי.

**גרירת קו ההפרדה** — במקום הסליידר, כעת גוררים את הגבול בין הסיכום לצ׳אט כדי לשנות את הרוחב. גם ניווט מקלדת (חצים שמאל/ימין).

**קישורים להרצאות קודמות בסיכום** — כשבונים סיכום להרצאה 3 ואילך, ה-AI מקבל קישורים לסיכומים הקודמים עם שמות הסעיפים. במקום להסביר שוב חומר שכבר נלמד, הוא מוסיף תזכורת קצרה וקישור לסעיף המתאים.

**כפתור "שלח דוח למפתח"** — נפתח GitHub Issue מוכן עם הלוג הטכני (אירועי תגובה ושגיאות בלבד, ללא מפתחות, שיחות או חומרי קורס). הסטודנט מוסיף תיאור ולוחץ Submit; אין שליחה אוטומטית לשרת.

**שיפורי מידע קורס** — קריאת מקורות הסילבוס כוללת עכשיו גם את תיקיית "כללי"; תוצאה כמעט ריקה לא נשמרת. מידע הקורס מציג גם מתרגלים, תאריכים מהסילבוס, ומסמך המידע המלא אם נשמר.

**ניקוי הגדרות** — כרטיס "סיכומים בפורמט ישן" ומתג "PDF כהה" הוסרו ממסך ההגדרות; קובצי PDF ממשיכים להשתמש בהעדפה השמורה.

**שם הצ׳אט** — שונה מ"שאל את Gemini" ל"שיחה על הסיכום" כי עכשיו הוא תומך גם ב-ChatGPT וב-Claude כגיבוי.
