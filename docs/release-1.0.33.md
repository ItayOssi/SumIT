# SumIT 1.0.33 (macOS)

- **הקורסים נפתחים גם כשה-Moodle למטה.** התיקון הועבר מגרסת ה-Windows (1.0.25), והותאם ל-macOS.
  - **עותק שמור.** כל פעם ש-Moodle עונה, רשימת הקורסים והדף הראשי נשמרים בקובץ במחשב. בכניסה לאפליקציה הרשימה השמורה מופיעה מיד, והרשימה העדכנית מחליפה אותה כש-Moodle עונה. אם אין עותק שמור, הקורסים נבנים מתיקיות הקורס שכבר קיימות במחשב.
  - **בלי חלון התחברות.** פתיחת קורס שכבר הורדת, בדיקת חומר חדש וניחוש המרצה ברקע לא פותחים יותר את חלון ההתחברות. כש-Moodle למטה או שההתחברות פגה, האפליקציה ממשיכה לעבוד עם מה ששמור, בלי הודעת שגיאה.
  - **דף ראשי.** כש-Moodle לא עונה, מוצג השבוע האחרון שנשמר.
  - **הודעה ברורה.** במקום "צריך להתחבר" מופיע "אין חיבור ל-Moodle כרגע. הקורסים והחומר שכבר הורדת פתוחים כרגיל", עם כפתור "נסה שוב". ההודעה הישנה נשארת רק כשאין שום קורס שמור.

חשוב: קורס שלא הורדת ממנו כלום ואין לו תיקייה במחשב עדיין לא ייפתח בלי Moodle. בפעם הראשונה צריך להתחבר ולטעון את רשימת הקורסים.

נבדק: 310 בדיקות נסיגה (10 חדשות): רשימה מהתיקיות, רשימה שמורה מול תיקיות, קובץ פגום, טעינה כש-Moodle למטה בלי שגיאה ובלי חלון התחברות, שגיאה עדיין מוצגת כשאין שום דבר שמור, דף ראשי מהעותק, פתיחת קורס מקומי בלי Moodle. לא נוסה באפליקציה עצמה מול Moodle אמיתי שנפל. גרסת ה-Windows בפורק הזה לא עודכנה.
