# SumIT 1.0.49 (macOS)

- **דף חדש אחרי האישור ב-Google.** אחרי שמאשרים את ההתחברות בדפדפן, נפתח עכשיו דף בעיצוב של SumIT במקום טקסט פשוט על רקע לבן.
  - בדף יש את הלוגו של SumIT וסימן וי ירוק, עם אנימציה קצרה. הדף מוצג בבהיר או בכהה, לפי ההגדרה של המחשב.
  - הוא מסביר מה קרה: הפרופיל, הסיכומים והמטלות יישמרו ב-Google Drive, והסנכרון הראשון כבר התחיל.
  - אם האישור בוטל או נכשל, מופיע דף עם סימן אדום, הסבר קצר ואיך לנסות שוב.

נבדק: 529 בדיקות נסיגה. הדף נבדק בדפדפן, בבהיר ובכהה. ההתחברות לא נבדקה מול Google האמיתי.
